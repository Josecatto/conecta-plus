# CONECTA+

**Antes de publicar, piensa. Antes de compartir, comprende.**

Sitio web educativo sobre ciudadanía digital y uso responsable de las redes sociales para estudiantes de 7.º a 10.º grado. Taller final del curso TICE (Facultad de Educación) · Grupo 2: Fabiana Guerra y Laura Marcelo.

## Secciones
- **Inicio:** bienvenida, propósito y objetivo educativo.
- **1. Identidad digital:** huella activa y pasiva, video y la actividad "¿Lo publicarías?".
- **2. Ciberacoso:** formas, señales, video, simulación de chat y líneas de ayuda.
- **3. Noticias falsas:** señales de alerta, ruta de verificación y la actividad "¿Real o sospechosa?".
- **4. Privacidad:** medidor de contraseñas y simulador de configuración de perfil.
- **5. Reto final:** evaluación, autoevaluación y compromiso personal.
- **Créditos:** autoras y referencias.

Es un solo archivo `index.html`, sin dependencias externas salvo los videos de YouTube. Las respuestas no se envían a ningún servidor.
